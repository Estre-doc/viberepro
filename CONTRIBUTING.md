# Contributing

Use Node.js 22.13+ and pnpm 11.25.0. Install dependencies and Chromium as described in the README, then run `pnpm check` and `pnpm pack:smoke`.

Keep detection grounded in observed browser evidence. Prefer a minimal local fixture for a new detector or false-positive fix. Do not add external site scans to tests. A detector change should include a positive reproduction and a healthy/control case.

Keep browser page functions serializable: transpiler helpers and Node closures cannot run in `page.evaluate`. End-to-end tests import the production build so they exercise the published path. No `any` escapes or suppressed type diagnostics.

New dependencies require an SPDX license check. Run `pnpm licenses:generate`, review `docs/DEPENDENCIES.json` and `THIRD_PARTY_NOTICES.txt`, then `pnpm licenses:check`. Keep source and compiled assets out of the same directory. Production output is generated by `pnpm build`.

Before submitting a change, describe the actual behavior and validation. Remove sensitive URLs/content from shared reports. The first version deliberately excludes auto-repair, cloud upload, accounts, login flows, and billing.

For baseline changes, cover new observations, persistent failures, verified absence, and missing/partial/redirected coverage. Keep resource origins and viewports significant. Do not let a successful exit imply that skipped baseline pages were checked. See [matching rules](docs/COMPARISON.md) and [contributor-sized tasks](docs/ROADMAP.md).
