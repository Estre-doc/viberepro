# VibeRepro v0.1.0

Give your coding agent a browser bug it can reproduce, then verify what changed.

VibeRepro scans initial page loads in Chromium and writes an offline evidence pack: an interactive HTML report, structured JSON, actual screenshots, a coding-agent repair brief, and a shareable Markdown summary. No account, model API key, or cloud upload is needed to use the scanner.

## In this release

- Observe JavaScript errors, HTTP failures, transport failures, broken images, and mobile document overflow, with explicit attribution and coverage limits.
- Scan a bounded set of same-origin pages at desktop and mobile viewports.
- Compare with a baseline: new, still present, resolved, and unverified observations. Missing or incomplete visits never count as verified repairs.
- Use `--fail-on-new` for regression checks, or `--fail-on-issues` to gate every current finding. Incomplete scans/comparisons exit 2.
- Review the HTML entirely offline, filter findings, inspect screenshots, and copy or download a repair brief.

## Install from npm

Requires Node.js 22.13+. Install Chromium once, then scan a running app:

```sh
npx viberepro@0.1.0 install
npx viberepro@0.1.0 http://localhost:3000 --out before
npx viberepro@0.1.0 http://localhost:3000 --baseline before/report.json --out after --fail-on-new
```

[View the npm package](https://www.npmjs.com/package/viberepro). Chromium is downloaded separately. The npm publication includes updated installation instructions and a prepack hook that does not require global pnpm. Its runtime files match the original GitHub release; existing GitHub assets and the tag remain unchanged.

## Try it from source

Requires Node.js 22.13+ and pnpm 11.25.0:

```sh
git clone https://github.com/Estre-doc/viberepro.git
cd viberepro
pnpm install --frozen-lockfile
pnpm browser:install
pnpm demo:generate
```

The deterministic demo applies predefined fixture repairs and verifies **11 → 0 observations**, with 11 resolved, 0 new, and 0 unverified. These are observations across viewports, not 11 independent root causes. This demo does not use AI to repair arbitrary source code.

## Install the release tarball

Download `viberepro-0.1.0.tgz` from this release, then run. On Windows PowerShell, use `npm.cmd` for these `npm exec` examples so CLI flags are forwarded correctly:

```sh
npm exec --yes --package ./viberepro-0.1.0.tgz -- viberepro install
npm exec --yes --package ./viberepro-0.1.0.tgz -- viberepro http://localhost:3000 --out before
npm exec --yes --package ./viberepro-0.1.0.tgz -- viberepro http://localhost:3000 --baseline before/report.json --out after --fail-on-new
```

The separate source ZIP includes development sources and examples; the npm tarball includes the built runtime and notices. Chromium is downloaded separately.

## Validation and scope

Local Windows validation passed 24 tests, typechecking, lint, production build, dependency-license checks, and installation in a fresh consumer. The repository's CI checks Linux Node 22/24 and Windows Node 22. See the actual Actions run for hosted results.

Only initial page loads are covered: no login sessions, clicks, forms, visual pixel comparison, accessibility, or SEO checks. Selectors are DOM hints, not source locations. Review URLs, stacks, and screenshots before sharing a report. Scan only sites you control or have permission to visit.
